# 邮件助手 README

把邮箱导出的 `.eml` 文件批量解析成 xlsx 清单、分类汇总、会议日程、附件原件和日历邀请文件。单文件 Python 程序，仅用标准库；界面为 Tkinter，可打包成免安装的 Windows 程序。

- 规则版本：13
- 程序版本：1.0.13.0
- 适用系统：Windows 10 / 11
- 依赖：无第三方库；打包版不需要 Python

## 目录结构

```
mail assistant/
├── README.md                本文件
├── 邮件助手使用说明.docx      面向使用者的 6 章说明
├── 源码/
│   ├── read_eml.py            核心：解析、分类、清洗、导出
│   ├── read_eml_gui.py        界面：Tkinter 工作台
│   └── version_info.txt       exe 版本资源（作者、版权、备注）
└── 邮件助手/
    ├── 邮件助手.exe           打包产物（onedir，整包约 26.4 MB）
    └── _internal/             运行库与 Tcl/Tk 资源
```

## 快速开始

**用打包版**：双击 `邮件助手/邮件助手.exe`，选邮件目录与输出目录，点“开始处理”。

**用源码**：需要 Python 3.10 以上，无需安装依赖。

```bash
python read_eml_gui.py                                  # 打开界面
python read_eml.py "D:\mail" -o "D:\out" --attachments   # 只在命令行跑
```

## 界面

- 顶部：邮件目录、输出目录、六个开关（递归子目录、导出附件、分类汇总、日历邀请、完整清单、强制重建）、界面语言。
- 左侧：邮件列表（分类、收件时间、发件人、主题），表头可排序；分类下拉与搜索框只筛界面显示。
- 右侧：`原文` 页显示清洗后的正文，被删内容按原因上底色；`元信息` 页上半是字段，下半是本封附件列表，双击用默认程序打开，右键可在文件夹中显示。
- 底部：运行日志与进度。每轮结束写出扫到文件数、入表封数、重复封数、日历个数，以及清单、汇总、日程、索引的路径。

## 命令行

```
python read_eml.py [路径 ...] [-o OUT] [--recursive] [--pattern PATTERN]
                   [--attachments] [--no-body] [--full] [--no-summary]
                   [--no-calendar] [--quiet] [--rebuild] [--lang {zh,en}]
```

| 参数 | 作用 |
| --- | --- |
| `paths` | .eml 文件、所在目录或通配符，可给多个 |
| `-o, --out` | 输出目录，默认 `./eml_output` |
| `--recursive` | 递归搜索子目录 |
| `--pattern` | 文件匹配规则，默认 `*.eml` |
| `--attachments` | 导出附件到 `<out>/attachments` |
| `--full` | 输出 13 列完整清单；默认 5 列 |
| `--no-body` | 配合 `--full`，xlsx 不写正文列（正文仍在索引里） |
| `--no-summary` | 不生成 `eml_summary.md` |
| `--no-calendar` | 不导出日历邀请 |
| `--quiet` | 不打印摘要 |
| `--rebuild` | 忽略上次基线，强制全量重建 |
| `--lang` | 表头与日志语言：`zh`（默认）或 `en` |

## 输出文件

| 文件 | 内容 |
| --- | --- |
| `eml_result.xlsx` | 邮件清单，一封一行。默认 5 列：发件人、收件时间、邮件主题、正文内容、分类；`--full` 为 13 列 |
| `会议日程.xlsx` | 会议类邮件整理的日程表，9 列：会议组织者、会议议题、会议时间、会议形式、会议安排、会议号+链接、参会人、状态、来源邮件 |
| `eml_summary.md` | 分类汇总：各类封数与每封要点 |
| `.eml_index.json` | 精简索引：正文、附件路径、日历事件，供界面回看与增补运行 |
| `.eml_state.json` | 处理基线：规则版本与表结构，决定下一轮走增补还是全量 |
| `calendar/*.ics` | 邮件里日历邀请另存的日历文件 |
| `attachments/<收件日期 邮件名>/` | 附件原件；没有附件的邮件不建目录 |

xlsx 由 zipfile 手写 SpreadsheetML，不依赖 openpyxl。

## 分类与正文清洗

类别有通知、日报、沟通三类，另有会议类与兜底的其他类。判定顺序即优先级：主题命中记 3 分、正文命中记 1 分，取最高分归类。

会议类只由日历邀请（ICS）判定。正文里通知开会但没有邀请的邮件归通知类，同时仍进会议日程表，来源列注明“正文通知，无日历邀请”。

正文只留本封自写的内容，剔除四类：引用历史、签名档、收尾寒暄、套话声明。被剔除的内容不丢弃，按原因记录并在界面用底色标出（引用历史淡紫、签名档淡绿、收尾语淡橙、套话淡黄；整封没有自写正文标淡红）。

去重：按 Message-ID 只计一次；主题相同而内容不同的两封都保留。

## 增补与全量

输出目录里已有清单与基线时，默认只解析新出现的邮件，结果并入既有清单、汇总、会议日程，附件只导出新邮件的。

以下情况自动退回全量重建，并先说明原因：首次运行、基础清单缺失或列结构变化、有邮件被移出目录或被改动。需要强制全量时加 `--rebuild` 或勾“强制重建”。

## 语言

界面右上角切换中英文，按钮、表头、提示一并切换并记住。输出语言跟随界面语言：英文下表头为 `From / Received / Subject / Body / Category`，会议日程为 `Organizer / Topic / Time ...`。输出文件名不随语言改变。

英文界面对应的命令行写法：`--lang en`。

## 配置

界面配置保存在 `%APPDATA%\eml_workbench\config.json`，记录邮件目录、输出目录、各开关、界面语言与窗口尺寸。删除该文件即恢复默认。配置不随程序包走。

## 可移植性

打包为 onedir，整个 `邮件助手` 文件夹一起拷贝即可在别的 Windows 机器上运行，不装 Python、不联网、无授权校验，中文路径可用。

需要注意：输出目录里 `.eml_index.json` 的 `file` 与 `saved_path` 是绝对路径。整包换机后，附件双击会提示文件不在本机，需要用新路径重跑一次。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 提示主文件被占用，结果另存为副本 | 结果表正在 Excel 里打开，关闭后重跑即可写回主文件 |
| 运行很快结束、没有新内容 | 目录里没有新邮件；确认目录与“递归子目录”设置，或勾“强制重建” |
| 附件双击提示文件已不在这台机器上 | 附件被移动或删除，重跑一次会按记录重新写入输出目录 |
| 界面读不到历史结果 | 索引缺失时回退读旧 jsonl；点一次“强制重建”即可迁移 |
| exe 被杀毒软件拦截 | 把整个文件夹加入信任名单 |
| 文字发虚或显示不全 | 已做高分屏适配；仍异常时把显示缩放调回 100% |

## 作为库调用

```python
from read_eml import read_eml_file

msg = read_eml_file("a.eml")
print(msg["subject"], msg["body_text"])
```

`read_eml_file(path, save_attachments=False, attach_root=None, attach_subdir=None, trace=None)`；`trace` 传入 list 可拿到删除原因明细。
